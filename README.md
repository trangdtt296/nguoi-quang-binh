## Công nghệ dự kiến

Next.js 15 (React + TypeScript) + Tailwind · Node.js + Express + TypeScript · PostgreSQL + Prisma · JWT · TipTap · Cloudinary · Lucide Icons

## Hạ tầng (toàn bộ miễn phí)

Vercel (frontend) · Render (backend) · Neon (PostgreSQL) · Cloudinary (ảnh)

## Phạm vi

Website truyền thông cộng đồng. **Không** có bán tour, giỏ hàng, thanh toán hay đặt tour.
